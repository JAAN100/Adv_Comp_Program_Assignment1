_Assignment_
Develop a complete REST API project using Express.js and Modular MVC Architecture, including Authentication, Category CRUD, and Course CRUD functionalities.
Required Modules

1. Authentication System: /api/auth
2. Category Module CRUD: /api/categories
3. Course Module CRUD: /api/courses
   _Submission Protocol (Mandatory Evidence)_
   _Students must submit the following two items:_
4. Source Code: GitHub Repository Link OR ZIP File.
5. Postman Evidence PDF / Screenshots: The following five cases are mandatory:

- Screenshot 1: Successful /register and /login responses.
- Screenshot 2: POST /api/categories with a 201 Created status.
- Screenshot 3: GET /api/categories with a 200 OK status.
- Screenshot 4: A 400 Bad Request validation error when a required field is missing.
- Screenshot 5: A 404 Route Not Found error when an invalid ID or unknown URL is accessed.
  _Printout Guidelines for Postman Evidence_
- The printed screenshots must clearly show the Postman Window's Top Bar, including the URL, HTTP Method, and Headers, as well as the Response Section at the Bottom, including the Status Code (200/201/400/404) and Response Body.
- The student's Name and Roll Number/ID must be written or printed at the top of each page.
